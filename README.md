# 📊 E-commerce Funnel Analysis

## 🔎 Project Overview

This project analyzes e-commerce user behavior and conversion performance using SQL and Google BigQuery.

The analysis focuses on the customer journey from page views to completed purchases, traffic source performance, user journey timing, and revenue metrics.

## 🎯 Business Questions

- How effectively do users move through the purchase funnel?
- Where does the largest drop-off occur?
- How does conversion performance vary by traffic source?
- How long does the average customer journey take?
- What revenue and order metrics characterize the analyzed period?

## 🛠️ Tools & Skills

- SQL
- Google BigQuery
- Looker Studio
- Conversion Funnel Analysis
- Customer Journey Analysis
- Traffic Source Analysis
- Revenue Analysis
- Data Visualization

## 📈 Analysis

The SQL analysis includes:

- Overall conversion funnel
- Funnel performance by traffic source
- User journey timing
- Revenue and order metrics

The results were visualized in Looker Studio to support business-oriented interpretation and recommendations.
